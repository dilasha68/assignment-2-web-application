# Introductory Portfolio and Blog

A multi-page web-development assignment built with HTML, CSS, JavaScript, and Bootstrap. It demonstrates page navigation, reusable blog data, query-string routing, and dynamic rendering into list and detail views.

## Pages

- `index.html` — introductory portfolio page and non-persistent feedback demo
- `blog_list.html` — blog cards generated from JavaScript data
- `blog_detail.html?id=1` — selected blog detail view

## Run locally

Open `index.html` in a browser. An internet connection is required for the Bootstrap stylesheet loaded from jsDelivr.

## Scope

This is a front-end coursework project. The feedback form intentionally does not send or store data, and the blog entries are local sample content.
